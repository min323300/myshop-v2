🏪 대리점 페이지 생성기

각 대리점의 카카오톡/SNS 공유 전용 HTML 파일을 자동으로 생성합니다

📌 이 도구가 필요한 이유 카카오톡 링크 미리보기는 JavaScript 실행 전 HTML의 OG 태그를 읽습니다. ?dealer=subi 파라미터만으로는 대리점별 다른 미리보기가 불가능하여, 대리점마다 OG 태그가 포함된 전용 HTML 파일이 필요합니다.

🏬

대리점 목록을 불러오세요

📖 사용 방법

1
위에서 Apps Script URL과 쇼핑몰 URL을 입력하고 목록 불러오기 클릭
2
각 대리점의 HTML 다운로드 버튼으로 파일 저장 (예: subi.html)
3
다운로드한 파일을 GitHub myshop-v2 저장소 루트에 업로드
4
카카오톡 OG 캐시 초기화: developers.kakao.com/tool/clear/og
5
대리점에게 gasway.shop/subi.html 형태의 URL 공유
